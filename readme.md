# 🎙️ Real-Time Voice Translator

A personal project built to explore speech recognition, machine translation, and text-to-speech using Python.

The purpose of this repository is not to create a production-ready application from the beginning, but to learn, experiment, and gradually improve the project while documenting the entire development journey.

---

## 🚀 About

This repository serves as a personal learning playground where I can experiment with different technologies related to audio processing and artificial intelligence.

As the project evolves, I'll be sharing my progress on LinkedIn, discussing challenges, improvements, and lessons learned throughout the development process.

Community feedback and suggestions are always welcome.

---

## ✨ Current Features

- 🎤 Capture live audio from the microphone
- 🗣️ Convert English speech into text
- 🌍 Translate English to Portuguese
- 🔊 Read the translated text using Text-to-Speech
- 🧠 Keep a short conversation history to improve translation context

---

## 🛠️ Built With
